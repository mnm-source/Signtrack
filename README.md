# ORL-SignTrack — UI Prototype

ต้นแบบหน้าจอระบบบริหารวงจรชีวิตป้ายและกราฟิก MRT Orange Line (ORL-GRS) ใช้เพื่อรีวิวเท่านั้น

- เปิด `index.html` (หรือหน้า GitHub Pages ของ repo นี้) เพื่อดูทุกหน้าจอ
- แต่ละหน้าเป็นไฟล์ `.dc.html` เปิดตรงในเบราว์เซอร์ได้ ต้องต่อเน็ต (โหลดฟอนต์และตัวช่วยแสดงผลจาก CDN)
- ข้อมูลเป็นตัวอย่าง ยกเว้นตัวเลขความคืบหน้าผลิต/ติดตั้งที่อ้างอิงไฟล์ Progress GRS ณ 12 พ.ย. 2569
- ปุ่มบันทึก/ส่งในต้นแบบไม่ส่งข้อมูลไปที่ใด

## ให้ความเห็น
เปิด Issue พร้อมระบุชื่อหน้าจอ (เช่น "Screen 13 · Repair Management") และสิ่งที่อยากให้ปรับ

## โครงสร้าง
- `*.dc.html` — หน้าจอแต่ละหน้า
- `support.js` — ตัวช่วยแสดงผลของไฟล์ .dc.html
- `thumbs/` — ภาพตัวอย่างสำหรับหน้า index
